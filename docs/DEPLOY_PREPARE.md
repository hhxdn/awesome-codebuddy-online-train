## 2. 域名

### 2.1 要求

- 域名需与服务器在同一服务商购买，方便备案
- 国内服务器必须完成 **ICP 备案** 才能通过域名访问
- 如果需要使用微信支付/微信登录，域名需备案完成

### 2.2 购买地址

| 厂商 | 地址 |
|------|------|
| **腾讯云** | [https://buy.cloud.tencent.com/domain](https://buy.cloud.tencent.com/domain) |
| **阿里云** | [https://wanwang.aliyun.com](https://wanwang.aliyun.com) |

### 2.3 费用参考

| 域名类型 | 首年价格（参考） | 续费价格 |
|----------|:--:|:--:|
| .com | ~60-80 元 | ~80-100 元/年 |
| .cn | ~30-50 元 | ~50-70 元/年 |
| .com.cn | ~30-50 元 | ~50-70 元/年 |

### 2.4 备案流程

1. 购买域名和服务器后，在对应服务商控制台找到 **ICP 备案** 入口
2. 提交主体信息（个人需身份证，企业需营业执照）
3. 提交域名信息、网站名称（不能使用敏感词汇）
4. 服务商初审 → 管局审核（通常 **7-20 个工作日**）
5. 备案通过后，在网站底部添加备案号链接

> **重要：** 备案期间域名无法使用，建议提前启动备案流程。

## 3. SSL 证书

### 3.1 说明

- 微信小程序要求后端 API 必须使用 **HTTPS**
- H5 页面和微信支付回调也建议走 HTTPS
- 浏览器 HTTPS 化是大趋势，没有证书会显示"不安全"

### 3.2 方案对比

| 方案 | 价格 | 适用场景 | 购买地址 |
|------|:--:|------|------|
| **腾讯云免费证书** | 免费 | 测试/小规模运营，有效期 90 天需定期续期 | [控制台 → SSL 证书](https://console.cloud.tencent.com/ssl) |
| **阿里云免费证书** | 免费 | 同上，单域名，有效期 90 天 | [控制台 → SSL 证书](https://yundun.console.aliyun.com) |
| **商业 DV 证书** | ~100-500 元/年 | 正式运营，1 年有效期无需频繁续期 | 腾讯云/阿里云 SSL 证书页 |
| **Let's Encrypt** | 免费 | 需自建 certbot 自动续期（有一定运维成本） | [https://letsencrypt.org](https://letsencrypt.org) |

### 3.3 购买地址

## 4. 腾讯云 COS（对象存储）

### 4.1 用途

存储课程封面图、Banner 图、新闻图片、用户头像等静态文件。

### 4.2 容量估算

| 资源类型 | 单文件大小 | 预估数量 | 小计 |
|------|:--:|:--:|:--:|
| 课程封面图 | ~200KB | 50 门 | 10MB |
| Banner 轮播图 | ~500KB | 10 张 | 5MB |
| 新闻封面图 | ~300KB | 100 篇 | 30MB |
| 用户头像 | ~100KB | 500 人 | 50MB |
| 其他图片 | ~200KB | 按需 | 20MB |
| **合计（一年）** | | | **约 120MB** |

> 图片建议统一存储为 **WebP 或 JPEG 压缩格式**，可进一步减少 50% 以上存储量。

### 4.3 开通步骤

1. 登录 [腾讯云控制台](https://console.cloud.tencent.com/)
2. 搜索 **对象存储 COS** → 开通服务
3. 创建存储桶：
   - 名称：自定义（如 `online-train`）
   - 地域：建议与服务器同地域（如广州 `ap-guangzhou`）
   - 访问权限：**公有读私有写**
4. 创建 API 密钥：[访问管理 → API密钥管理](https://console.cloud.tencent.com/cam/capi)

### 4.4 费用参考

| 计费项 | 计费方式 | 费用估算（年） |

| CDN 加速流量 | 按流量计费（可选） | 视访问量而定 |
| API 请求 | 按调用次数 | ~几元 |

> **新用户优惠：** 50GB 免费存储额度（有效期 6 个月），初期基本不花钱。

## 5. 微信支付

### 5.1 前提条件

| 条件 | 说明 |
|------|------|
| ✅ 已备案域名 | 支付回调地址必须使用已备案域名 |
| ✅ 微信公众平台账号 | AppID 和 AppSecret |
| ✅ 商户号 | 企业或个体工商户均可申请 |

### 5.2 注册步骤

1. **注册微信支付商户号**
   - 访问 [https://pay.weixin.qq.com](https://pay.weixin.qq.com)
   - 点击"接入微信支付" → 注册商户号
   - 需要：营业执照、法人身份证、对公银行账户（个体工商户可用法人个人银行账户）
   - 审核通常 **1-5 个工作日**

2. **获取 AppID（微信公众号/小程序）**
   - 访问 [https://mp.weixin.qq.com](https://mp.weixin.qq.com)
   - 注册服务号或小程序
   - 完成认证（300 元/年认证费）

3. **关联 AppID 和商户号**
   - 登录 [微信支付商户平台](https://pay.weixin.qq.com) → 产品中心 → AppID 账号管理 → 关联 AppID

4. **配置 API 密钥**
   - 商户平台 → 账户中心 → API安全
   - 设置 APIv3 密钥（32 位随机字符串）
   - 下载商户证书（apiclient_key.pem）
   - 记录证书序列号

### 5.3 费用参考

| 项目 | 费用 |
|------|:--:|
| 商户号注册 | 免费 |
| 公众号/小程序认证 | 300 元/年 |
| 交易手续费 | 0.6%（从每笔交易中扣除） |

## 8. 微信小程序注册

### 8.1 用途

如果需要在微信生态内上线小程序学员端，学员可以直接在微信中搜索和使用，无需下载。

### 8.2 前提条件

- 未注册过微信小程序的邮箱（一个邮箱只能注册一个小程序）
- 已备案的域名（小程序要求 API 请求必须是 HTTPS）

### 8.3 注册步骤

1. 访问 [微信公众平台](https://mp.weixin.qq.com) → 立即注册 → 选择 **小程序**
2. 填写**邮箱**，激活后填写主体信息：
   - 企业：营业执照、法人身份证、对公账户打款验证
   - 个体工商户：营业执照、经营者身份证、银行卡打款验证
   - 个人：身份证（但个人主体限制较多，推荐企业或个体户）
3. 完成微信认证（300 元/年），认证后才能使用微信支付等能力
4. 完善小程序信息：名称、头像、介绍、类目
5. 配置服务器域名：
   - 开发管理 → 开发设置 → 服务器域名
   - **request 合法域名**：填写后端 API 域名（如 `https://study.youruanhui.com`）
   - **uploadFile 合法域名**：填写图片上传域名（同后端域名或 COS 域名）
   - **downloadFile 合法域名**：填写资源下载域名
6. 在项目 `miniapp/project.config.json` 中填入小程序 AppID

### 8.4 代码中的配置

修改 `miniapp/app.js` 第 4 行，将 `baseUrl` 改为生产环境地址：

```javascript
baseUrl: 'https://你的域名/api'
```

| 项目 | 费用 |
|------|:--:|
| 小程序认证 | 300 元/年 |

### 8.6 注册地址

## 10. 微信小程序备案

### 10.1 说明

根据工信部要求，所有小程序必须完成 **ICP 备案** 才能正式发布上线。自 2023 年 9 月起，未备案的小程序无法上架。

### 10.2 备案前提

| 条件 | 说明 |
|------|------|
| 已完成小程序注册和认证 | 认证后方可进入备案流程 |
| 域名已完成 ICP 备案 | 小程序需填写已备案的服务域名 |
| 主体信息完备 | 营业执照、法人身份证等 |

### 10.3 备案流程

1. 登录 [微信公众平台](https://mp.weixin.qq.com) → 进入小程序后台
2. 设置 → 基本设置 → **备案** → 点击"去备案"
3. 填写主体信息：
   - 主办单位名称（与营业执照一致）
   - 主办单位证件号
   - 法人姓名、身份证号
   - 应急联系电话
4. 填写小程序信息：
   - 小程序名称
   - 小程序服务内容（选择"教育"类目）
   - 前置审批（教育类一般不需要前置审批，除非涉及学历教育）
5. 填写域名信息：
   - 填写已备案的 API 域名
6. 上传证件照片：
   - 营业执照（彩色扫描件）
   - 法人身份证正反面
   - 若非法人操作，需上传**授权书**
7. 人脸核身验证（法人或授权人）
8. 提交审核 → 平台初审（1-3 个工作日）→ 管局审核（约 **7-20 个工作日**）

### 10.4 备案后操作

| 步骤 | 说明 |
|------|------|
| 添加备案号 | 小程序首页底部需展示备案号，并链接到工信部备案查询 |
| 定期检查 | 备案信息变更（如主体变更、域名变更）需及时更新 |

### 10.5 注意事项

- 小程序备案与域名 ICP 备案是**独立的两个流程**，都要完成
- 个人主体小程序备案审批更严格，建议使用企业/个体户主体
- 教育类小程序备案时，"服务内容"选择"教育"即可，一般不需要额外审批
- 备案期间小程序可以继续开发调试，但不影响备案审核
